# Week-9-Stickfigure-Storyboarder
Plan It:

What is the goal of this website?

Create an app where the user can create storyboards.

Who are you building for, and what do they care about?

It is for theatre people who want to clearly express their ideas.

Describe how a user should use Stickfigure Storyboarder from the moment they visit it. What should they see first, what should they click, and what should happen next?

There will be a scene in the middle the user can add to. At the bottom is a timeline.

How should Stickfigure Storyboarder work (stick figures, mouse puppeteering, movement tracking, basic timeline)?

The storyboards will be made out of stickmen. There will be a timeline where the user can navigate between frames to animate the stickman. The user can click a button to begin a new project. They start with one stickman, and can add more. They can change the background by adding images, from Google Images.

How should the site look and feel for film and theatre club students blocking scenes?

The background will be white.

Test It:

Edit Pose. Put nodes on the stickmen that can be moved. Add the ability to add colors. Make the frames move faster upon playback.

Expand It:

Share Button in top right. Menu pops up when clicked. Menu has video and timeline. Drag and drop the parts to include. Only the selected frames will be sent.
